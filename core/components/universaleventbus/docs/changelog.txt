1.3.3-rc
==============
- FIX: в данные товара уходит цена показа, а не цена ресурса из msProductData. Там, где
  товар собирается из ресурса (листинг по $_REQUEST['ids'], вызовы getProductData() без
  своей цены, данные страницы товара), шина отдавала msProductData.price — цену, которую
  покупатель на витрине не видит, если у товара есть модификации msOptionsPrice. Аналитика
  из-за этого считала выручку по несуществующей цене: view_item и select_item расходились
  с add_to_cart на том же товаре. Цену считает сам msOptionsPrice методом
  getCostByModification(): выбрана модификация — по ней, не выбрана — минимум по активным,
  модификаций нет — цена товара. Позиции корзины и заказа приносят собственную цену и
  пересчёту не подлежат.
- FIX: выбранная в листинге модификация больше не теряется. getProductsData() кладёт её
  идентификатор в ключ mid, а getProductVariant() читал только modification и options —
  вариант приходил пустым, хотя фронт модификацию передал.
- FEATURE: событие OnUebGetPageData ($pageData, $EventBus) — точка, где плагин может
  дополнить или изменить данные страницы ($EventBus->pageData). Раньше данные страницы
  были недоступны для правки: OnUebHandleEvent отдаёт каждому плагину свою копию output,
  а единственная точка над товаром, OnUebGetProductData, на странице товара не вызывается.

1.3.1-rc
==============
- FIX: кука контекста снова ставится на домен основного контекста, а не на его первый
  символ. fetch(PDO::FETCH_COLUMN) возвращает значение колонки строкой, а обращение [0]

  вместе с языком и site_url. На однодоменных сайтах дефект не проявлялся.

1.3.0-rc
==============
- FEATURE: adaptive local transport без внешних сервисов. Активная вкладка держит bounded
  SSE с heartbeat, после idle переходит на короткий cursor polling с backoff, скрытая
  вкладка не держит PHP worker. BroadcastChannel оставляет один transport на browser profile.
- FEATURE: события хранятся до TTL в локальной таблице <prefix>ueb_events с cursor и UUID;
  SSE освобождает PHP session lock до цикла. Событие не удаляется при первом чтении, поэтому
  новая страница или вкладка может дочитать его до TTL.
- FIX: click по обычной ссылке с data-ueb-event ждёт запись события не дольше
  ueb_navigation_timeout и перед переходом останавливает transport текущей страницы.
  Это устраняет гонку отменённого fetch при выгрузке документа.

1.2.5-pl
==============
- Логирование переведено с файлов (logs/*.txt) на mxLogger. Хелпер Logging делегирует
  записи сервису mxLogger (если установлен), иначе молчит и один раз предупреждает в
  журнале MODX. Перевод затронул EventBus и QueueManager.
- Гейты: ueb_debug (вкл/выкл) + новая настройка ueb_log_level (минимальный уровень
  debug|info|warning|error, по умолчанию error; единый приёмник mxLogger, включено из коробки). Консистентно с mxLogger.min_level.
  QueueManager теперь учитывает ueb_debug (раньше new Logging() без гейта).
- Тэги: базовые universaleventbus + events, этапные order (orderData), queue (очередь).
  Воронка process_uid = «universaleventbus_»+md5(branch) — события одной сессии/ветки
  склеиваются в mxLogger одним процессом.
- Сигнатура Logging::write сохранена (позиционные method/msg/data), добавлены параметры
  $level и $tags. Уровни: дампы resourceData/orderData/SQL — debug; пустая ветка/данные
  очереди — warning.
- ВНИМАНИЕ: перед сборкой настройку ueb_log_level создать в менеджере (namespace
  universaleventbus) — сборка тянет настройки из БД стенда.
